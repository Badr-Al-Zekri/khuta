## 🌟 نظرة عامة | Overview

**خُطى (Khuta)** هو تطبيق ويب تفاعلي صُمم لحل واحدة من أكبر المشكلات التي تواجه الشباب عند محاولة تحسين حياتهم: **«فخ الحماس المؤقت»**. 
عند بداية أي تغيير، ينطلق الكثيرون بحماس مرتفع وأهداف مثالية ضخمة، ولكن مع أول ضغط أو يوم شاق، يفوّتون يوماً واحداً فيشعرون بالذنب والفشل التام، مما يدفعهم للاستسلام والانقطاع.

تطبيق «خُطى» لا يعاملك كآلة ولا يقدم لوحة بيانات جوفاء؛ بل يقدم **نظام استمرارية مرن (Flexible Consistency)** يعتمد على أحدث أبحاث علم السلوك وتكوين العادات (*Atomic Habits* لجيمس كلير و*Tiny Habits* لـ د. بي جيه فوج).

## 🧠 الركائز العلمية والسلوكية للتطبيق | Behavioral Architecture

1. **الحد الأدنى الواقعي (Micro-Habit Baseline):**
   - لكل عادة هدفان: **الهدف الكامل** (في الأيام العادية وارتفاع الطاقة) و**الحد الأدنى الواقعي** (سلوك لا يتجاوز دقيقتين يُنجز حتى في أشد الأيام إرهاقاً).
   - *مثال:* قراءة 20 صفحة (كامل) ⟵ قراءة صفحة واحدة فقط (الحد الأدنى).
2. **تسجيل ثنائي المستوى بنقرة واحدة (Full vs. Minimum Completion):**
   - زر للإنجاز الكامل وزر للحد الأدنى، وكلاهما يحافظ على استمرارية السلسلة ويحمي هويتك الإيجابية من الانكسار.
3. **قاعدة «لا تفوّت يومين متتاليين» (Never Miss Twice):**
   - تفويت يوم واحد أمر إنساني طبيعي؛ التعثر الحقيقي هو تفويت يومين متتاليين. يوفر التطبيق إشعاراً سلوكياً داعماً عند تعثر اليوم السابق للاستئناف الفوري.
4. **المحفزات السلوكية الراسخة (Habit Cues):**
   - ربط كل عادة بمحفز يومي موجود أصلاً (مثل: "بعد فنجان القهوة الصباحي" أو "بمجرد إطفاء أضواء الصالة").
5. **المراجعة الأسبوعية الذكية القائمة على البيانات الحقيقية:**
   - تحليل موضوعي يكشف العادة الأكثر انتظاماً، والعادة التي تتكرر فيها العثرات، واليوم الأكثر تشتتاً في الأسبوع.
   - اقتراح **تعديل عملي واحد فقط** قابل للتنفيذ الفوري دون ادعاءات نفسية غير مدعومة.

## ✨ المميزات الرئيسية | Key Features

- 📅 **لوحة متابعة يومية ذكية:**
  - عرض التاريخ باللغة العربية بتنسيق هجري/ميلادي واضح.
  - مؤشر إنجاز دائري ديناميكي يحسب نسبة إنجاز اليوم والمهام المتبقية.
  - إحصاءات حقيقية: معدل الالتزام الأسبوعي، نسبة التغير مقارنة بالأسبوع السابق (+/-)، أطول سلسلة متواصلة، وإجمالي أيام الإنجاز.
- 📊 **رسم بياني تفاعلي للأيام السبعة:**
  - أعمدة مكدسة تبرز بوضوح نسبة الإنجاز الكامل (الأخضر) والحد الأدنى (الفيروزي) والانقطاع.
  - إمكانية النقر على أي يوم لاستعراض عاداته أو تصحيح تسجيلاته السابقة.
- 🗓️ **خريطة الالتزام الشهرية (35-Day Consistency Heatmap):**
  - تقويم بصري متكامل للأسابيع الخمسة الماضية لتتبع وتيرة الاستمرارية وحماية سجل الأيام غير الصفرية (Non-zero days).
- 📝 **سجل تفصيلي وملاحظات لكل عادة:**
  - إمكانية إضافة ملاحظة سريعة لكل يوم لتوثيق العقبات أو الإنجازات.
  - نافذة تاريخية لمراجعة آخر 21 يوماً لأي عادة مع إمكانية تعديل أي يوم بأثر رجعي.
- ⚙️ **إدارة مرنة لدورة حياة العادة:**
  - إضافة، تعديل، إيقاف مؤقت دون حذف السجل التاريخي، وحذف نهائي.
  - تصنيف العادات حسب المجالات الحياتية (الصحة، التعلم، العمل، الروحانية، الانضباط الرقمي).
  - فلترة سريعة حسب فترات اليوم (الصباح، المساء) أو حالة الإنجاز.
- 🔒 **خصوصية تامة وتخزين محلي (Local-First):**
  - حفظ موثوق وفوري في المتصفح (`LocalStorage`) دون خوادم وسيطة أو تتبع.
  - تصدير نسخة احتياطية كاملة بصيغة `JSON`.
  - استيراد واسترجاع النسخ الاحتياطية بنقرة واحدة.
  - توفير بيانات تجريبية واقعية مدمجة لاستكشاف قدرات النظام ومسحها في أي وقت للبدء بسجل فارغ.

## 🛠️ التقنيات المستخدمة | Tech Stack

- **الواجهة:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **محرك التصميم:** [Tailwind CSS v4](https://tailwindcss.com/) مع دعم كامل للاتجاه من اليمين لليسار (`dir="rtl"`)
- **الأيقونات:** [Lucide React](https://lucide.dev/)
- **الخطوط:** `IBM Plex Sans Arabic` و `Plus Jakarta Sans`
- **الحركات والتفاعل:** Canvas Confetti للاحتفال بالإنجاز، و CSS transitions مريحة
- **أداة البناء والتطوير:** [Vite 8](https://vitejs.dev/)

## 🚀 التشغيل المحلي | Getting Started

### المتطلبات المسبقة:
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- npm أو pnpm أو yarn

### خطوات التثبيت والتشغيل:

```bash
# 1. تثبيت الحزم المطلوبة
npm install

# 2. بدء سيرفر التطوير المحلي
npm run dev

# 3. بناء نسخة الإنتاج النهائية
npm run build
```
